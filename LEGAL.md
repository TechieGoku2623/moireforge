# Legal and Third-Party Code

## Purpose

This document helps avoid legal risk from **accidental use of others’ code**: we do not intentionally include anyone’s code without proper **license and attribution**.

## What we do

1. **Third-party code is listed** in **`THIRD_PARTY_LICENSES.md`** with:
   - Copyright holder  
   - License (e.g. ISC, MIT, Apache)  
   - Source URL or repository  

2. **Only permissively licensed code** is included: code that explicitly allows use, modification, and distribution (e.g. ISC, MIT, Apache 2.0), with attribution as required.

3. **No one is named or implicated** beyond correct attribution: we do not claim others’ code as our own, and we do not include code that would subject the project or contributors to legal proceedings for misappropriation.

## If you contribute

- Do **not** add code from other projects (including snippets, scripts, or RTL) unless:
  - It is under a permissive license that allows it, and  
  - You add an entry in **`THIRD_PARTY_LICENSES.md`** with copyright, license, and source.  
- When in doubt, do not include the code; link to it or document how to obtain it instead.

## Current third-party components

The repo **does not include any third-party RTL**. See **`THIRD_PARTY_LICENSES.md`** for the policy and for attribution if you add optional external code (e.g. PicoRV32).
